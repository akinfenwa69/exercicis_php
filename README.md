# EXERCICIS PHP

## Miniaplicació

A l'exercici 5.1 hi ha dos miniaplicacions:

- **Exemple 1**. Mostra el nom i comprova si ets major d'edat.
- **Exemple 2**. Ens dóna per escollir un/diversos productes d'una llista i la quantitat que volem. Després calcula el subtotal, mostra un missatge (gran o petita compra) i ho mostra en format taula HTML. Per finalitzar, aplica descomptes possibles segons la quantitat.

## Conceptes PHP aplicats

He aplicat conceptes bàsics com variables, `echo` o `if`, però també he utiitzat conceptes més complexos com les llistes i bucles.

A part, les funcions també han tingut presencia, juntament amb una miniaplicació, usant formulari HTML.
