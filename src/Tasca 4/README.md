# Què s'ha fet?

- Practicar connexió a una base de dades amb PDO
- Entendre estructura MVC
- Implementar CRUD senzill amb dades reals de MySQL
- Practicar l'ús de _prepared statements_ i la técnica Post/Redirect/Get (PRG)
- Mostrar dades en la taula HTML i gestionar-les mitjançant formularis
