# Aplicació CRUD

## Què fa aquesta aplicació?

En aquesta aplicació l'usuari podrà veure, crear, modificar i eliminar (Create Read Update Delete) usuaris de la base de dades enllaçada.

## Conceptes aplicats

Hem utilitzar diversos aspectes relacionats amb connexions, així també com algunes funcions que ens permeten realitzar accions CRUD.

Per això utilitzarem formularis HTML amb conjunt dels `$_GET` i `$_POST`, a part d'altres funcions que ens permeten fer peticions SQL.
